# Assets and provenance

`bunker.css` contains original procedural bunker-wall and felt textures authored for Outpost Poker. Card faces/backs are original CSS in `src/ui/components/cards.css`; animations are in `src/ui/animations.css`. Fictional identity shield/monogram placeholders are CSS, not real military insignia or downloaded portraits. Fonts are system fonts. No third-party artwork, audio, game branding or custom fonts are used.

Place future original or appropriately licensed images, fonts and audio here. Import through Vite so packaged builds use relative paths. Record source, author and license for each third-party asset.
